SHREE RAM PHOTOGRAPHY — WEBSITE

Files: index.html, style.css, script.js

PREVIEW:
Extract ZIP and open index.html in Chrome or Edge.

PUBLISH ON GITHUB PAGES:
1. Create a new public GitHub repository (example: shree-ram-photography).
2. Upload index.html, style.css and script.js to the repository root.
3. Go to Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Wait for the published URL to appear.
